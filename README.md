# 东南亚官方媒体账号清单

调研范围：东盟10国 + 东帝汶，仅国家电视台/国际频道/官方通讯社（不含商业台）。截至 2026-08-25。

## 文件

| 文件 | 说明 |
|---|---|
| `01_机构总表.csv` | 24家机构：国家/机构名/类型/官网/备注 |
| `02_账号明细.csv` | 49个平台账号：优先级/国家/机构/平台/Handle/URL/备注 |

## Excel 导入（UTF-8 CSV）

1. **推荐**：Excel 空白工作簿 → 数据 → 获取数据/从文本或CSV → 选文件 → 编码选 **UTF-8** → 加载。中文不乱码。
2. 直接双击打开若中文乱码：文件 → 另存为 → 选「CSV UTF-8（逗号分隔）.csv」格式后重开即可。
3. 两表分别导入后就是两个 sheet；或导入后复制粘贴为值即可。

## 使用建议

- **优先级1 = 核心监测（约35个）**，优先级2 = 补充覆盖。
- 标「待核验/待核实」的账号（MITV 各平台、NBT WORLD 的 YT、PTV 的 YT 等）采集前先打开链接确认。
- 平台习惯：ID/MY/PH/KH 以 Facebook 为主阵地；VN/SG/TH 的 YouTube/TikTok 更强；缅甸重度使用 Telegram；IG 在东南亚渗透低，按资源补充即可。
- 缅甸 DVB/Mizzima 是流亡/反对派媒体，未列入本表（如需监测可单列）。

## 核验来源

- 各机构官网；ABU 成员名单（abu.org.my，2025-10）；机构自述。
- 账号 handle 均来自官网/官方页面或已验证的平台主页。
